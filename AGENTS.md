# Shared Documentation Rules

For README and repository-metadata tasks, the canonical source of truth is:

- https://github.com/Dream22180971/dream22180971/blob/main/docs/README_DESIGN_SYSTEM.md
- https://github.com/Dream22180971/dream22180971/blob/main/docs/repository-metadata.json

Before modifying documentation:

1. Inspect the current implementation first.
2. Verify every install/run command against real repository files.
3. Keep `README.md` English-first and `README.zh-CN.md` as the full Chinese version.
4. Preserve the language switch in both files.
5. Use project-specific visuals; do not copy the same visual gimmick across repositories.
6. Do not add typing animations to project READMEs.
7. Use semantic emoji headings where useful.
8. Never fabricate screenshots, GIFs, features, commands, releases, URLs, test status, supported platforms, or roadmap completion.
9. Keep repository Description short, English, and value-oriented; use canonical Topics from the metadata registry.
10. Treat code/configuration as the source of truth when documentation conflicts with implementation.
11. README work is not complete until the README Quality check has been reviewed.
